Transparent von Anfang an

Neben dem Angebot für Gestaltung und Umsetzung können laufende Kosten bei Drittanbietern entstehen. Sie werden dir vorab einzeln genannt, damit es keine Überraschungen gibt.

Domain

Die Gebühr für das erste Jahr übernehme ich. Danach geht die Domain über Namecheap in dein Eigentum über, und die laufende Gebühr zahlst du direkt beim Anbieter.

Hosting

Deine Website wird über GitHub Pages bereitgestellt. Das Hosting ist kostenlos.
